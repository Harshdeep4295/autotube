# Privacy Policy — Run It Local Uploader

_Last updated: 30 September 2026_

**Run It Local Uploader** is a private automation tool operated by the owner of the YouTube
channel **Run It Local** ([@RunItLocalAI](https://www.youtube.com/@RunItLocalAI)). It is not offered
to the public and has no other users.

## What it does
The tool signs in to the owner's own Google account with OAuth and uses the YouTube Data API to:

- upload videos the owner has produced to the owner's own channel,
- set their title, description, tags, thumbnail, captions and playlist,
- read basic information about the owner's own channel and videos.

## Data it accesses
- **OAuth tokens** for the owner's account. They are stored only as an encrypted GitHub Actions
  secret in the owner's repository and are never shared.
- **The owner's channel and video metadata**, used only to perform the actions above.

The tool does **not** access, collect or store data about any other person, YouTube viewer or
Google user. It does not sell, share or transfer any data, and it does not use data for
advertising.

## Google API Services
Use of information received from Google APIs follows the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements. The tool uses YouTube API Services; see the
[YouTube Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).

## Revoking access
The owner can revoke access at any time in
[Google Account → Security → Third-party connections](https://myaccount.google.com/connections).
